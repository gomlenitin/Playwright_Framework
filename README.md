# Playwright Framework

A test automation framework built with Playwright for end-to-end testing.

## Overview

This project provides a comprehensive testing framework using Playwright, a modern automation library that supports all major browsers and provides powerful APIs for test automation.

## Requirements

- Node.js (LTS recommended)
- npm or yarn

## Installation

1. Clone the repository:
```bash
git clone https://github.com/gomlenitin/Playwright_Framework.git
cd Playwright_Framework
```

2. Install dependencies:
```bash
npm install
```

## Project Structure

```
Playwright_Framework/
├── node_modules/        # Project dependencies
├── .gitignore          # Git ignore file
├── package.json        # Project configuration and dependencies
├── README.md           # Project documentation
└── .vscode/            # VS Code settings
```

## Usage

To run tests:
```bash
npm test
```

## Technologies Used

- **Playwright** - Automation framework for testing web applications
